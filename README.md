# QSkill Data Analytics Internship

This repository contains the work completed during my **QSkill Data Analytics Internship (Slab 2 – Intermediate)**.

## 📌 Tasks

### Task 1 – E-Commerce Customer Churn Prediction
Performed data cleaning, exploratory data analysis, feature engineering, and classification modeling to predict customer churn and identify important factors affecting customer retention.

### Task 2 – Time Series Sales Forecasting
Analyzed historical sales data, identified trends and seasonal patterns, created time-based features, and developed forecasting models to predict future sales.

### Task 3 – End-to-End Fraud Detection & Risk Analysis
Analyzed financial transaction data, performed data preprocessing and feature engineering, handled class imbalance, and built classification models to detect fraudulent transactions and evaluate fraud risks.
